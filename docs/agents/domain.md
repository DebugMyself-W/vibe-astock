# Domain Docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read relevant ADRs under `docs/adr/` when that directory exists.
- If either location is absent, proceed without treating the absence as an error.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issues, tests, diagnoses, and implementation notes. Avoid synonyms that the glossary explicitly rejects.

## Architectural decisions

If a proposed change conflicts with an existing ADR, surface the conflict explicitly instead of silently overriding the decision.
